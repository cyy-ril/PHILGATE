# PHILGATE - Philippine Artisan Crafts Web Application

## 1. Overview
The Web Application, PHILGATE is a fully responsive e-commerce and cultural showcase web application built for discovering, browsing, 
and celebrating traditional Philippine arts, crafts, and indigenous products (such as Walis Tambo, T’nalak, Yakan Fabric, Banig, Pottery, and more).
It features a comprehensive product catalog with detailed descriptions, a shopping cart, responsive mobile menu navigation, and a dedicated contact/about ecosystem.

## 2. Setup and installation
**What to install first:**
- Get the latest version of Node.js.
- This also need a code editor (VS Code recommended) with a git for cloning.
- You'll also need a web browser (Google Chrome, Firefox, or Safari) with developer tools.

**How to get the code (clone)**
```bash
git clone https://github.com/cyy-ril/PHILGATE.git (sample)
cd PHILGATE
```
**How to install dependencies**
- Open directly via a local server (e.g., Live Server in VS Code)

## 3. What it does

- Home & Landing Experience: Features a culturally rich introduction to Filipino craftsmanship complete with high-resolution imagery and direct calls to action.

- Interactive Shop & Catalog: Browse authentic Philippine crafts with detailed modal popups displaying item descriptions and history.

- User Authentication: Sign up, log in, and validate mock credentials [does not use a database; handled entirely through client-side JavaScript and local state logic].

- User Profile Management: Interactive profile dashboard displaying purchase history categories, total expenditures, and editable account details 
[does not use a database; handled through front-end state and form alerts].

- About & Contact Section: Provides a direct communication channels (Facebook, Email, Phone) and reference links to major articles supporting Philippine arts and artisans.

- Responsive Mobile Navigation: Provides a built-in hamburger menu toggle ensuring smooth usability across mobile, tablet, and desktop screens.

## 4. Built With
- HTML5 & Modern CSS3: Structured in a semantic elements styled with a responsive Flexbox and CSS Grid layouts.

- Tailwind CSS & Font Awesome: Utility-first styling frameworks paired with a vector icon suites for clean interface design.

- JavaScript (ES6+): Responsive menu toggles, form state handling, and interactive modal alerts.
